# Commandes utiles

## Lancer l'application

```bash
npm start
```

Avec `rtk` :

```bash
rtk npm start
```

## Lancer les tests Jest

```bash
npm test
```

Avec `rtk` :

```bash
rtk npm test
```

## Lancer les tests Playwright

```bash
npm run test:e2e
```

Avec `rtk` :

```bash
rtk npm run test:e2e
```

## Regenerer les captures Playwright

```bash
npm run test:e2e:update
```

Avec `rtk` :

```bash
rtk npm run test:e2e:update
```
